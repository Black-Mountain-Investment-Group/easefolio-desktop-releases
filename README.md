# Easefolio for desktop

Downloads and automatic updates for the Easefolio desktop app for Mac and Windows.

**Get it at [easefolio.com/download](https://easefolio.com/download)**, or pick a file from the [latest release](https://github.com/Black-Mountain-Investment-Group/easefolio-desktop-releases/releases/latest):

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 and later) | `Easefolio-mac-apple-silicon.dmg` |
| Mac with Intel | `Easefolio-mac-intel.dmg` |
| Windows 10 or 11 (64-bit) | `Easefolio-windows-setup.exe` |

Already installed? Easefolio updates itself.

This repository only hosts release files. Questions: support@easefolio.com
